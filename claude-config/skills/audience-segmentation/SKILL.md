# Audience Segmentation

## Overview

This skill creates detailed audience segments for advertising and marketing campaigns. It defines demographics, psychographics, behaviors, and interests for each segment, maps them to platform-specific targeting options across Meta, Google, LinkedIn, and TikTok, estimates audience size and reach, builds buyer personas, and recommends lookalike audience strategies.

## When to Use This Skill

- When planning a new advertising campaign and need to define target audiences
- When existing campaigns have broad targeting and need refinement
- When expanding into new markets or audience segments
- When building buyer personas for content or product marketing
- When setting up lookalike or similar audiences on ad platforms
- When analyzing which customer segments drive the most value

## How It Works

1. Gather business context, product/service details, and existing customer data
2. Identify and define distinct audience segments
3. Build detailed profiles with demographics, psychographics, and behaviors
4. Map segments to platform-specific targeting parameters
5. Estimate audience sizes and recommend budget allocation per segment
6. Create buyer personas and suggest lookalike strategies

## Instructions

### Step 1: Gather Business Context

Ask the user for:

- **Product/Service**: What they sell and its key value propositions
- **Current customers**: Who buys today (demographics, common traits)
- **Price point**: Affects income and intent targeting
- **Geography**: Target markets and regions
- **Sales cycle**: Impulse buy vs. considered purchase
- **Existing data**: Any customer surveys, analytics, or CRM data available

### Step 2: Define Audience Segments

Create 3-6 distinct segments. Each segment should be:

- **Measurable**: You can estimate its size
- **Accessible**: You can reach it through available ad platforms
- **Substantial**: Large enough to justify dedicated campaigns
- **Differentiable**: Distinct from other segments in meaningful ways
- **Actionable**: You can create targeted content and offers for it

Name each segment with a memorable label (e.g., "Budget-Conscious Beginners", "Enterprise Decision Makers").

### Step 3: Build Segment Profiles

For each segment, define:

**Demographics**:
- Age range
- Gender (if relevant)
- Income level / household income
- Education level
- Job title / industry / company size (for B2B)
- Location (country, region, urban/suburban/rural)
- Family status

**Psychographics**:
- Values and beliefs relevant to the product
- Lifestyle characteristics
- Personality traits (early adopter vs. risk-averse, etc.)
- Media consumption habits
- Brand affinities

**Behaviors**:
- Purchase behavior (frequency, average spend, preferred channels)
- Online behavior (search patterns, content consumption, social media usage)
- Technology adoption level
- Current solutions they use (competitor products)

**Interests**:
- Hobbies and activities
- Topics they follow
- Influencers or thought leaders they engage with
- Publications, podcasts, or communities they belong to

Present each segment in a structured format:

```
SEGMENT: Growth-Stage Founders
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Demographics:
  Age: 28-42
  Income: $80K-$200K
  Education: Bachelor's or higher
  Role: CEO, Founder, Co-founder
  Company size: 5-50 employees
  Location: US, UK, Canada (urban)

Psychographics:
  Values: Speed, efficiency, growth, innovation
  Lifestyle: Always-on, mobile-first, conference attendees
  Risk profile: Moderate -- willing to try new tools but need proof

Behaviors:
  Searches: "best [tool category] for startups", "how to scale [function]"
  Content: Reads TechCrunch, Hacker News, SaaS blogs
  Social: Active on Twitter/X and LinkedIn

Pain Points:
  - Wearing too many hats, need to automate
  - Limited budget but high expectations
  - Need tools that scale with them

Motivation:
  - Save time on manual tasks
  - Look professional to clients and investors
  - Get data-driven insights without hiring analysts
```

### Step 4: Map to Platform-Specific Targeting

For each segment, provide targeting parameters per platform:

**Meta (Facebook/Instagram)**:
- Interest targeting categories
- Behavior targeting options
- Custom audience sources (website visitors, email lists, app users)
- Detailed targeting inclusions and exclusions
- Placement recommendations (Feed, Stories, Reels)

**Google Ads**:
- In-market audiences
- Affinity audiences
- Custom intent audiences (keywords and URLs)
- Demographics overlays
- Campaign type recommendations (Search, Display, YouTube, Performance Max)

**LinkedIn**:
- Job titles and functions
- Company size and industry
- Seniority level
- Skills and groups
- Matched audiences options

**TikTok**:
- Interest categories
- Behavior targeting
- Creator interactions
- Hashtag targeting
- Device and connection targeting

### Step 5: Estimate Audience Size and Budget

For each segment, provide:

| Segment | Est. Audience Size | Recommended Daily Budget | Expected CPM Range | Priority |
|---------|-------------------|--------------------------|---------------------|----------|
| Growth-Stage Founders | 2.1M (Meta), 800K (LinkedIn) | $50-100 | $15-30 | High |
| Enterprise Buyers | 500K (LinkedIn), 1.2M (Google) | $100-200 | $25-50 | Medium |

Note: Audience size estimates should be based on platform targeting tools. Recommend the user verify in each platform's audience builder.

### Step 6: Create Buyer Personas

For the top 2-3 segments, create full buyer personas:

- **Name**: A fictional but representative name
- **Quote**: A sentence that captures their mindset
- **Day in the life**: A brief narrative of their typical day
- **Decision-making process**: How they evaluate and purchase
- **Objections**: Common reasons they might not buy
- **Preferred content formats**: Blog, video, podcast, case study, webinar
- **Messaging angle**: The primary message that resonates with this persona

### Step 7: Lookalike Audience Strategies

Recommend lookalike/similar audience approaches:

- **Source audience**: Which customer list or pixel data to use as the seed
- **Similarity level**: 1% (most similar) to 10% (broader reach) and when to use each
- **Layering**: Combining lookalikes with interest or demographic targeting
- **Exclusions**: Current customers, recent purchasers, existing leads
- **Testing plan**: Start with 1% lookalike, expand to 3-5% if performance holds

## Best Practices

- Start with 3-4 segments maximum to keep campaigns manageable
- Validate segments against actual customer data when available
- Refresh segments quarterly as market conditions and customer profiles evolve
- Avoid over-narrowing -- segments under 100K on Meta or 10K on LinkedIn limit delivery
- Test segment hypotheses with small budgets before committing large spend
- Use exclusion targeting to prevent segment overlap and audience cannibalization
- Document the rationale for each segment so the strategy is repeatable
- Consider the full funnel: awareness segments should be broader, conversion segments narrower
- Cross-reference segments with actual conversion data to identify highest-value audiences
- Account for platform differences in how audience sizes are reported
